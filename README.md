# ☕ Coffee Shop E-Commerce

A full-stack e-commerce app for a coffee shop, built with React, Node/Express, MongoDB, and Stripe.

## Features
- Product catalogue with cart functionality
- User authentication (JWT + bcrypt)
- Stripe payment integration
- RESTful API backend

## Tech Stack
React · Node.js · Express · MongoDB · Tailwind CSS · Stripe

## Getting Started
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your keys
3. `npm install`
4. `npm run dev`
